# Oni Class

Windows용 교실 관리 프로그램의 설치본과 업데이트를 배포하는 저장소입니다.

## 다운로드 및 설치

[Releases](https://github.com/yang102948549/oni-class/releases)에서 버전별 `OniClass_버전_x64-setup.exe` 파일을 내려받아 실행하세요. Windows x64 설치형만 제공합니다.

설치 후 시작 메뉴에서 Oni Class를 실행합니다. 이후 업데이트는 **설정 → 앱 업데이트 → 업데이트 확인 → 업데이트 설치**에서 진행합니다.

`beta-channel`은 앱이 사용하는 업데이트 정보입니다. 직접 설치할 때는 버전이 표시된 릴리스의 setup.exe를 사용하세요.
